1. Tujuan

Praktikum ini bertujuan untuk memahami cara menghubungkan CSS eksternal dengan HTML. Selain itu, praktikum ini juga bertujuan untuk membuat tampilan website menjadi lebih rapi dan menarik untuk dilihat dengan menggunakan CSS. Pada praktikum ini juga dipelajari tentang reset ukuran kotak, token warna dan jarak, tipografi dan unit, serta organisasi dan audit dalam CSS.

2. Penjelasan Perubahan

Pada praktikum ini dilakukan beberapa perubahan pada halaman formulir dari praktikum sebelumnya. Perubahan yang dilakukan adalah menambahkan beberapa kode CSS agar tampilan website menjadi lebih rapi, menarik, dan tersusun. Setelah itu, file CSS dihubungkan dengan file HTML supaya kode CSS yang dibuat dapat digunakan pada halaman website.

3. Hasil Uji

Berdasarkan hasil pengujian yang dilakukan, file CSS berhasil terhubung dengan file HTML dan perubahan yang dibuat dapat terlihat pada halaman website. Bagian pengisian data diri menjadi lebih rapi dan teratur. Ukuran setiap bagian dan tata letaknya juga mengalami perubahan sesuai dengan CSS yang telah dibuat.

4. Batasan

Praktikum ini masih menggunakan halaman formulir yang sederhana. Pengujian juga dilakukan pada lingkungan lokal dengan menggunakan browser, sehingga hasil yang dilihat masih berdasarkan website yang dijalankan pada komputer.
