2. Langkah Pengerjaan (Git Workflow)

1. Membuat branch baru untuk fitur: git switch -c fitur-petunjuk
2. Melakukan perubahan kode dan commit: git add . dan git commit -m "..."`
3. Membandingkan perubahan (diff): git diff main...fitur-petunjuk`
4. Menggabungkan kembali (merge) ke branch utama: `git switch main lalu git merge fitur-petunjuk
