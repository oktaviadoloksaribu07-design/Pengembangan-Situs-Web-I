1. Cara Menjalankan
Buka folder web di Visual Studio Code, buka file index.html lalu Klik kanan, pilih Open with Live Server Web akan terbuka di browser.

2. Penjelasan Perubahan
Saya menambahkan menu Beranda, Kegiatan, dan Kontak pada website. Saya juga mengubah warna judul menjadi merah muda, tombol menjadi ungu, dan card kegiatan menjadi hijau muda. Perubahan ini dilakukan agar tampilan website terlihat lebih menarik dan tidak terlalu polos.

3. Hasil Uji
Website berhasil dijalankan dan dibuka melalui browser. Bagian menu, profil, tujuan belajar, dan card kegiatan sudah tampil dengan baik. Namun, tombol salam dan menu navigasi masih perlu diperiksa kembali untuk memastikan apakah sudah berfungsi dengan benar.

4. Batasan
Website yang dibuat masih sederhana dan informasi di dalamnya belum bisa berubah secara otomatis. Tombol salam masih membutuhkan JavaScript agar dapat digunakan. Menu navigasi juga perlu diperiksa untuk memastikan setiap menu mengarah ke bagian yang sesuai. Selain itu, card kegiatan masih tersusun ke bawah dan belum berjajar. Website ini juga belum menggunakan database untuk menyimpan informasi.
