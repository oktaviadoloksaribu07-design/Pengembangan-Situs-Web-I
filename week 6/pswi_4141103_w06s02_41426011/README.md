1. Cara Menjalankan Web

Untuk membuka web, pertama buka folder proyek melalui Visual Studio Code. Selanjutnya, cari file index.html, klik kanan pada file tersebut, kemudian pilih Open with Live Server. Setelah itu, halaman web akan ditampilkan pada browser.

2. Penjelasan Perubahan

Pengamatan nomor 3. 
Saya mengatur tampilan website menjadi satu kolom dan mengujinya pada layar 320 px. Hasilnya, tampilan website menyesuaikan ukuran layar. Saya juga memeriksa apakah semua konten dan link tetap tersedia pada layar kecil.

Pengamatan nomor 4.
Saya mengatur tampilan katalog agar menjadi satu kolom pada layar kecil dan dua kolom pada layar yang lebih lebar. Saya juga menguji tampilan pada ukuran 767 px, 768 px, dan 769 px. Hasilnya, kartu kegiatan dapat tersusun menjadi dua kolom pada layar yang lebih lebar.

Pengamatan nomor 5.
Saya mengatur navigasi agar lebih rapi dan menambahkan CSS supaya elemen formulir tidak melebihi tempat nya. Saya juga mencoba tampilan pada layar kecil dan menggunakan tombol Tab untuk memeriksa apakah navigasi masih bisa digunakan atrau tidak.

Pengamatan nomor 6.
Pada nomor 6, saya mencoba mengatur lebar katalog menjadi 900 px untuk melihat apakah tampilan website mengalami overflow. Hasilnya, katalog menjadi terlalu lebar sehingga dapat menyebabkan halaman bergeser ke samping pada layar kecil stelah saya hapus, penyesuaian layar kembali ke semula.

3. Hasil Pengujian

Dari pengujian yang dilakukan, halaman web dapat ditampilkan dengan baik melalui browser. Selain itu, tampilan web dicoba menggunakan beberapa ukuran layar untuk mengetahui kemampuan web dalam menyesuaikan tata letaknya dengan ukuran perangkat.

4. Batasan Web

Web ini masih memiliki beberapa kekurangan karena informasi yang ditampilkan belum bersifat dinamis. Tombol salam belum dapat digunakan sepenuhnya karena masih memerlukan JavaScript. Tautan pada menu navigasi juga perlu diuji kembali untuk memastikan setiap menu menuju bagian yang benar. Selain itu, susunan card kegiatan masih perlu dikembangkan agar dapat ditampilkan berdampingan pada layar yang lebih luas. Web ini juga belum dilengkapi database untuk menyimpan data.
