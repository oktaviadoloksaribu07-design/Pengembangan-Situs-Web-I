1. Cara Menjalankan Web

Untuk menjalankan web, buka folder praktikum di Visual Studio Code, kemudian buka file index.html. Klik kanan pada file tersebut dan pilih Open with Live Server. Setelah itu, halaman web akan terbuka di browser dan tampilannya dapat diperiksa secara langsung.

2. Penjelasan Perubahan

Pada praktikum ini, saya membuat halaman web galeri kegiatan mahasiswa dengan menggunakan HTML dan CSS. Saya menerapkan gambar fleksibel agar ukuran gambar dapat menyesuaikan lebar layar tanpa mengubah perbandingan ukurannya. Saya juga menggunakan clamp() pada judul agar ukuran teks menyesuaikan ukuran layar. Selain itu, saya menerapkan *media query* untuk mengatur jumlah kolom pada layar kecil, tablet, dan desktop. Saya juga mempelajari penggunaan *container query* untuk menyesuaikan ruang di dalam kartu serta prefers-reduced-motion untuk mengurangi animasi sesuai preferensi pengguna.

 3. Hasil Pengujian

Pengujian dilakukan dengan membuka halaman web melalui browser dan memeriksa tampilannya pada ukuran layar yang berbeda. Hal yang diperiksa meliputi ukuran gambar, keterbacaan teks, susunan kartu, serta perubahan tampilan ketika lebar layar berubah. Pengujian juga perlu dilakukan dengan fitur zoom dan preferensi pengurangan gerakan untuk memastikan halaman tetap nyaman digunakan.


5. Kesimpulan

Melalui praktikum ini, saya mempelajari cara membuat halaman web yang responsif dengan menggunakan HTML dan CSS. Saya memahami bahwa gambar, ukuran teks, dan susunan kartu perlu menyesuaikan ukuran layar agar halaman lebih mudah digunakan. Saya juga mempelajari pentingnya memperhatikan preferensi pengguna dan melakukan pengujian untuk memastikan tampilan web berjalan sesuai kebutuhan.
