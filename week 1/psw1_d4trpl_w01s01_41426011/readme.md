                Refleksi fungsi HTML,CSS, dan JavaScript

1. HTML
HTML bertugas memberi tahu mengenai bagian-bagian dari sebuah halaman, seperti mana yang merupakan teks judul, paragraf tulisan, tombol yang bisa diklik, gambar yang harus ditampilkan, hingga link tautan yang menghubungkan ke halaman lain. Tanpa HTML, teks dan media di internet tidak akan bisa tersusun dengan rapi dan hanya akan tampil sebagai tulisan polos yang berantakan di layar komputer atau ponsel Anda. Jadi, fungsi utamanya adalah menjadi fondasi paling awal agar semua konten di internet bisa ditampilkan secara rapi, jelas, dan teratur.

2. CSS
CSS digunakan untuk mengubah warna teks, menentukan jenis font, mengatur ukuran konten, mengatur jarak antar-elemen, menentukan posisi objek, serta membuat halaman website otomatis menyesuaikan diri saat dibuka di layar HP maupun laptop. Selain itu, CSS juga berfungsi memisahkan isi konten website dari desain visualnya.

3. JavaScript
JavaScript berfungsi untuk mengatur perilaku atau aksi pada website tersebut. Ketika KITA mengeklik tombol dan muncul menu baru, melihat animasi bergerak, mengisi formulir yang langsung memeriksa kesalahan, atau melihat pembaruan data secara otomatis tanpa perlu memuat ulang halaman, semua proses itu dijalankan oleh JavaScript.
