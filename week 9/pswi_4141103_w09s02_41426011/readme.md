1. Cara Menjalankan
Buka direktori proyek menggunakan perangkat lunak Visual Studio Code. Jalankan aplikasi menggunakan ekstensi Live Server pada peladen lokal. Akses menu Dev Tools tekan F12 & Fn, lalu pilih tab Console untuk memantau hasil uji.

2. Pebjelasan Perubahan
- Menguji string "2" + 1 dengan hasil konversi menggunakan fungsi Number("2") + 1. Pemeriksaan tipe data juga diuji menggunakan fungsi JavaScript.
- Menerapkan validasi input menggunakan Number.isInteger() dan pemeriksaan rentang nilai (1 sampai 5) dengan struktur conditional if else.
- Menampilkan elemen di dalam array secara berurutan menggunakan struktur perulangan for.

3. Hasil Uji
- String & Angka    : Input "2" + 1 menghasilkan 21 
- Konversi Angka    : Input Number("2") + 1 menghasilkan 3 
- Tiket Valid       : Input jumlah tiket = 3 berhasil menghitung total harga sesuai ketentuan. 
- Nilai Batas       : Input jumlah tiket = 1 atau 5 berhasil diproses tanpa kendala. 
- Di Luar Rentang   : Input jumlah tiket = 0 atau 6 ditolak dan memunculkan pesan tidak valid. 
- Input Non-Numerik : Input berupa teks "abc" berhasil ditangkap oleh validasi error. 
- Array Kosong      : Perulangan for pada array kosong [] tidak melakukan iterasi.

4. Batasan
- Program saat ini masih dijalankan melalui console .
- Validasi input baru mencakup pemeriksaan tipe data dasar dan batas angka sederhana.
